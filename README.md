# Nolan Noronha · Portfolio

Personal school portfolio (Galaxy International School Uganda, Year 12, AS Levels 2026–27).

Live site: https://e1-diabl0.github.io/portfolio/

A static multi-page site: page text lives in `content.js`, layout and the lightbox in `script.js`, the homepage dot-portrait intro in `cover.js`, and styles in `styles.css`. Certificates, photos and StudyNest screenshots are in `assets/`.

To preview locally, open `index.html` in a browser.
